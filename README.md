# My Budget Tracker

## Week 3 Visual Identity

This project is a Budget Tracker designed to help users record and view their expenses.

## Color Palette

The project uses a consistent color palette:
- Dark blue for headings and table headers
- Teal for buttons and important actions
- Light blue/grey for the page background
- White for the main cards
- Light grey for table rows and borders

## Typography

Google Fonts are used to improve readability:
- Poppins is used for headings.
- Inter is used for body text, labels, inputs, buttons, and table content.

## Form Styling

The Add Expense form has:
- Proper spacing
- Styled input fields
- Rounded corners
- Borders
- A consistent button design
- Focus effects for inputs

## Expense Table

The expense table includes:
- Styled table headers
- Borders
- Padding
- Alternating row colors
- Hover effects
- Rounded corners

## CSS Box Model

The project uses:
- Margin between sections
- Padding inside cards and form elements
- Borders around sections
- Border-radius for rounded corners
- Box shadows to separate the cards visually

## Files

- `index.html` — contains the structure of the Budget Tracker.
- `style.css` — contains the visual styling.
- `README.md` — explains the project and its design choices.

## How to Run

Open `index.html` in a web browser to view the Budget Tracker.
